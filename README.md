# Coroko
Coroko

A modern iOS customization toolkit for Windows.

Coroko is an experimental project inspired by tools like Cowabunga and Nugget. It aims to provide a clean, glass-inspired interface for managing iOS customization projects.

✨ Features

* Modern UI — a dark interface inspired by the glass design language of iOS 26.
* Theme Library — import and organize theme assets.
* Passcode Studio — preview and prepare passcode theme files.
* Wallet Studio — customize card artwork and colors.
* Device Manager — check iPhone and iPad USB connectivity.
* Local Backups — save theme settings and project assets.
* Console — view diagnostic logs and operation status.

🚧 Development Status

Coroko is currently in early development.

The theme editor, local asset handling, and interface are under development. Direct theme installation on iOS is not yet implemented and depends on compatible installation methods and supported iOS versions.

💻 Platform

* Windows
* Python
* CustomTkinter

⚠️ Disclaimer

Coroko is an independent experimental project and is not affiliated with Apple. Features may be incomplete and compatibility is not guaranteed.

📌 Goal

Build an all-in-one iOS customization workspace with a modern interface and clearly documented feature support.
